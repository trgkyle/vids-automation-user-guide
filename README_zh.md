# 🚀 Vids Automation v1.0.0 - Google Vids AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Vids Automation** 是一款生产力扩展程序，可在 Google Vids (docs.google.com/videos) 上自动化您的创意工作流程。告别手动逐个输入提示词——实现流程自动化，大规模生成视频、图片和配音（voice-over）。

-----

## ✨ 主要功能

* **🚀 批处理：** 排队数十或数百个提示词，让扩展程序在 Google Vids 上自动提交和生成。
* **🧩 工作流（可视化拖放编辑器）：** 在画布上连接提示词、图片和生成节点——例如先生成图片，再自动用这些图片生成视频。可保存多个工作流，运行单个节点或全部运行，并以文件导入/导出。
* **🎬 文本转视频（自动 VEO 和 Nano Banana）：** 从文本描述生成高质量的视频。
* **🎬 帧转视频（图片转视频）：** 使用静态帧图像和运动控制提示词生成动态视频。
* **🎬 组件转视频（Ingredients-to-Video）：** 制作用户界面（UI）组件和布局的动画。支持每个提示词上传最多 **3 张图片**。
* **🖼️ 文本转图片批处理：** 批量生成高质量图片，支持自定义宽高比（16:9、9:16、1:1、2:3、3:2）。
* **🎙️ 文本转语音（配音）：** 将脚本段落文本转换为配音音频轨，支持自定义下载质量设置。
* **⚙️ 专业控制：**
    * **提示词延迟范围：** 设置提示词提交之间的自定义最小和最大时间间隔，以管理速率限制。
    * **自动下载：** 生成完成后自动下载高画质/音质的视频、图片或音频资源。
    * **输出数量限制：** 严格限制每个提示词生成最多 1 个输出，以实现最大效率。
* **📊 实时队列监控：** 通过侧边面板（Side Panel）的进度条和活跃提示词列表跟踪批处理任务。
* **📂 有序文件管理：** 自动下载的文件会按项目名称自动分类到子文件夹中。
* **🌐 多语言支持：** 英语、越南语、中文、韩语、日语、西班牙语。

## 📖 使用指南

### 开始使用

1. **导航至 Google Vids**
   - 打开 [docs.google.com/videos](https://docs.google.com/videos)
   - 确保已登录您的 Google 帐户。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议固定它以便快速访问！

3. **配置批量设置**
   - 在 **控制** 标签页中，您可以设置 **提示延迟**（两次提交提示词之间的最小/最大等待时间）。

4. **选择模式**
   - 选择：**文本转视频**、**帧转视频**、**组件转视频**、**文本转图片** 或 **文本转语音**。

### 1. 文本转视频模式

1. 选择 **文本转视频** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或者，点击 **上传** 按钮从 `.txt` 文件或 `.xlsx` / `.csv` 电子表格导入提示词列表。
4. 点击 **运行** 开始批量处理。

**示例提示词：**
```
一个充满霓虹灯的未来派赛博朋克城市，雨水倒映着灯光。
摄像机穿过狭窄的小巷。

一个宁静的日本花园，樱花飘落进池塘。
摄像机缓慢放大观察下方游动的锦鲤。
```

### 2. 帧转视频模式

1. 选择 **帧转视频** 模式。
2. 拖放或上传一张起始图片。
3. 输入描述运动的提示词（用空行分隔）。
4. 点击 **运行**。

### 3. 组件转视频模式

1. 选择 **组件转视频** 模式。
2. 上传组件帧图片（每个提示词支持最多 **3 张图片**）。
3. 输入详细说明组件如何运动的提示词。
4. 点击 **运行**。

### 4. 文本转图片模式

1. 选择 **文本转图片** 模式。
2. 输入由空行分隔的提示词。
3. 在设置标签页中配置所需的 **宽高比** 和 **图片模型**。
4. 点击 **运行**。

### 5. 文本转语音模式

1. 选择 **文本转语音** 模式。
2. 输入由空行分隔的配音文案段落。
3. 点击 **运行**。
4. 在设置标签页中，您可以自定义默认音频链接行为（`defaultAudioOption`）以及音频下载设置。

### 🧩 工作流（可视化拖放编辑器）

工作流是用于多步骤流程的可视化拖放编辑器——例如：先生成几张图片，再用这些图片生成视频，然后用另一个提示词延续每个视频。它在独立窗口中打开，并在您已打开的 Google Vids 标签页上运行。

#### 打开工作流

* 在控制标签页中点击 **工作流**（最下面一排按钮）。
* 已在侧边面板输入提示词或上传图片？将鼠标悬停在 **工作流** 上并点击 **转换为工作流**：提示词、每个提示词的模式和图片都会变成工作流中的节点，可直接运行。

#### 界面

| 区域 | 内容 |
| :--- | :--- |
| **左侧** | **节点**（点击或拖到画布上）和 **我的工作流**（已保存的工作流列表） |
| **顶部栏** | 画布工具：撤销/重做、**自动排列**、适应视图、**示例**、清空。右侧：**详情** 按钮、**快捷键** 和 Google Vids 标签页状态 |
| **画布** | 您的节点。左上角：**全部运行**（运行时还有 **停止**）和 **开启后台模式** |

**详情** 按钮提示需要注意的情况：有问题阻止运行时显示红色/黄色的 **问题 (n)**，生成时显示 **运行中 3/8**。点击可打开面板，查看问题（点击问题跳到对应节点）、进度、运行计划及所用设置。

#### 节点

| 节点 | 作用 |
| :--- | :--- |
| **输入提示词** | 一个或多个提示词，用 **空行** 分隔 |
| **上传图片** | 您的图片（可直接把文件拖到节点上）。悬停图片：🔍 放大查看，✕ 删除，拖动角上的手柄可调整顺序。顺序（或排序菜单）决定每个提示词使用哪张图片 |
| **生成图片** | 文本生成图片；连接图片后为图片生成图片。选项：**每个提示词的图片模式**、**每个提示词的最大输入图片数**、**自动添加角色图片** |
| **生成视频** | 文本生成视频；连接图片后为 **帧图生成视频** / **素材生成视频**。选项：**每个提示词的视频模式**、每个提示词的图片数（与侧边面板设置共用）、**自动添加角色图片**（素材生成视频） |

生成节点会根据第一个提示词自动命名（`image_…` / `video_…`）。每行提示词都会显示它将使用的图片，方便运行前检查。预览区域采用设置中的 **宽高比**（9:16 的节点更窄更高）。

#### 连接节点

从节点右侧的圆形连接点拖出，**放到另一个节点的任意位置**——会自动选择合适的输入口。拖动时，可以连接的节点会高亮。

| 从 | 到 | 含义 |
| :--- | :--- | :--- |
| 输入提示词 | 生成图片 / 生成视频 | 要生成的提示词 |
| 上传图片 | 生成图片 / 生成视频 | 参考图、起始帧或素材 |
| 生成图片 | 生成图片 / 生成视频 | **生成的图片** 作为该节点的输入（图片就绪后才运行） |
| 生成视频 — **最后一帧** 输出 | 生成视频 | 后一个视频 **从前一个视频的最后一帧继续** |
| 生成视频 — **最后一帧** 输出 | 生成图片 | 每个视频的 **最后一帧** 作为输入图片（视频就绪后才运行） |

#### 运行

* **全部运行**（左上角，或 `Ctrl/⌘ + Enter`）按正确顺序运行整个工作流：需要生成图片的节点会在图片就绪后自动开始。
* 如果 **全部运行** 不可用，顶部栏会显示 **问题 (n)**：点击查看需要修复的内容。
* 每个生成节点都有自己的 **运行** 按钮，只运行该节点。在其依赖的节点完成之前按钮不可用（悬停可查看原因）。
* **停止** 取消仍在运行的任务。
* 运行时，连向正在生成的节点的连线会发光并流动，让您看到工作流进行到哪一步。

> ⚠️ **Google Vids 标签页不可见时 Chrome 会暂停它**（例如工作流窗口全屏遮住它时）。点击 **开启后台模式**（工作流中 **全部运行** 按钮下方，或侧边面板中），然后在 Chrome 的对话框中选择 Google Vids 标签页。这会共享 Google Vids 标签页（不会录制或发送到任何地方），让它在其他窗口后面继续生成。绿色的 **后台运行中** 标识表示已开启；点击 ✕ 关闭。

#### 结果

结果直接显示在生成节点中。悬停结果：🔍 放大查看，✕ 删除（橡皮擦按钮清除该节点的全部结果）。悬停时视频自动播放。文件仍会照常下载。

下一个节点使用 **每个提示词的第一个结果**。要换成别的结果，拖动结果左上角的手柄放到另一个结果上即可交换位置（图片和视频均可）。

#### 管理工作流

在左侧的 **我的工作流** 中：**新建**、**导入**，以及每个工作流的 **⋯** 菜单——**重命名**（或双击名称）、**复制**、**导出**、**删除**。所有更改都会自动保存。

* **导出** 会下载一个 `.json` 文件。文件开头有 `//` 注释行，描述所有节点、属性和连接方式，因此您可以把文件交给 AI 助手，让它编写新的工作流。导入时会自动去掉这些注释行。
* 用 **导入** 按钮导入文件，或直接 **把 `.json` 文件拖到画布上**。

#### 编辑快捷键

点击顶部栏的 **快捷键**（或按 `?`）查看全部快捷键。

| 操作 | 按键 |
| :--- | :--- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 复制 / 剪切 / 粘贴节点（也可粘贴到其他工作流） | `Ctrl/⌘ + C / X / V` |
| 复制一份所选节点 | `Ctrl/⌘ + D` |
| 全选 / 加选 / 框选 | `Ctrl/⌘ + A` / `Ctrl/⌘ + 点击` / `Shift + 拖动` |
| 自动排列 | `Shift + A` |
| 删除所选 | `Delete` |
| 全部运行 / 后台运行 | `Ctrl/⌘ + Enter` / `Ctrl/⌘ + Shift + Enter` |

## ⚙️ 设置配置

访问 **设置** 标签页来自定义您的自动化工作流程：

* **默认模式：** 设置默认开启的标签页。
* **宽高比：** 选择默认宽高比（16:9、9:16、1:1、2:3、3:2）。
* **默认视频选项：** 默认时长配置（5秒 或 5秒-concat）。
* **默认图片选项：** 图片提示的默认输入模式（新建图片 或 编辑图片）。
* **默认音频选项：** 音频提示的默认时长/链接模式（新建音频 或 合并音频）。
* **自动下载视频质量：** 选择下载分辨率（不下载、480p、480p-upscale、720p）。
* **自动下载图片质量：** 选择图片分辨率（不下载、1k）。
* **自动下载音频质量：** 选择下载格式（不下载、Mp3 质量原声）。
* **自动更改文件名：** 自动重命名文件以符合文件夹和前缀。
* **文件夹名称：** 在您的“下载”目录中定义一个子文件夹，以保持文件井井有条。
* **最大重试次数：** 设置生成失败时扩展程序的重试次数。

## 💡 提示与最佳实践

1. **智能延迟：** 如果您遇到生成受限或限制，请增加控制标签页中的 **提示延迟** 范围。
2. **下载路径：** 确保关闭 Chrome 的下载位置提示（见下文），以允许文件自动下载。
3. **文件夹整理：** 在启动大批量生成之前，建议始终在设置中定义一个自定义 **文件夹名称**，以避免弄乱您的默认“下载”目录。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保您位于 [docs.google.com/videos](https://docs.google.com/videos)。如需请刷新页面。 |
| **弹出下载位置询问窗口** | 在 Chrome 浏览器的“设置 -> 下载”中，**关闭** “下载前询问每个文件的保存位置” 开关。 |
| **生成错误** | Google Vids 可能繁忙或受限。扩展程序将自动重试该提示词，直至达到配置的 **最大重试次数**。 |
| **需要登录** | 请确保已登录您的有效 Google Workspace 或有 Google Vids 访问权限的 Google 帐户。 |
| **工作流：结果一直停在“生成中”** | Chrome 暂停了被遮住的 Google Vids 标签页。开启 **开启后台模式**（或 **后台运行**），或保持 Google Vids 标签页可见。 |
| **工作流：某个节点的运行按钮不可用** | 将鼠标悬停在按钮上：先运行它依赖的节点，或修复提示的问题（例如未连接提示词）。 |
| **工作流：全部运行不可用** | 点击顶部栏的 **问题 (n)** 查看需要修复的内容；点击某个问题可跳到对应节点。 |
| **工作流：“未找到 Google Vids 标签页”** | 在标签页中打开 [Google Vids](https://docs.google.com/videos)（顶部栏的绿点表示已连接）。 |
